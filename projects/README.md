# Projetos

Esta pasta guarda exercícios incrementais que combinam vários conceitos da
trilha de aprendizagem.

Projetos planejados:

- `calculadora`: funções, pacotes, documentação e testes.
- `analisador-texto`: strings, runes, slices e maps.
- `todo-cli`: structs, erros, arquivos, JSON e CLI.
- `url-checker`: HTTP, goroutines, channels e context.
- `todo-api`: backend HTTP, banco de dados, logs e testes de integração.

Quando um projeto tiver um executável, seu `package main` deve ficar em
`cmd/<nome-do-programa>`. A lógica reutilizável permanece em `projects/<nome>`.
